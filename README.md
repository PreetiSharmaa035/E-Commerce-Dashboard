# E-Commerce Sales Dashboard

An interactive Excel dashboard for exploring e-commerce sales, order trends, product categories, regions, order statuses, and sales channels.

## 1. Project Overview

- This E-Commerce Sales Dashboard presents an at-a-glance view of sales performance and order activity.
- It brings key business metrics and visual analysis together in a single dashboard.
- Users can compare sales across product categories and states, follow monthly trends, and review order status and channel mix.
- The dashboard is designed to help stakeholders identify patterns and make informed business decisions.

## 2. Tools and Techniques

- Microsoft Excel for dashboard development and visualization
- PivotTables for summarizing and analyzing order data
- PivotCharts for category, regional, monthly, order-status, and channel analysis
- Spreadsheet formulas and aggregations for KPI calculations

## 3. Data Source

The dashboard is based on e-commerce order data. The workbook includes raw data and analysis sheets. The dashboard visualizes fields such as order amount, product category, state, month, order status, and sales channel.

## 5. Analysis Covered

- **Sales by Category** – Compare order amounts across Beauty, Books, Electronics, Fashion, and Home.
- **Sales by State** – Compare regional performance across states, including Maharashtra, Rajasthan, Tamil Nadu, Uttar Pradesh, and West Bengal.
- **Monthly Sales Trend** – Review order amounts across the months of the year.
- **Order Status Analysis** – See the distribution of cancelled, delivered, pending, and returned orders.
- **Sales by Channel** – Compare the contribution from the Mobile App and Website.

## 6. Business Insights

- Category and state comparisons help reveal where sales are concentrated.
- The monthly trend chart makes it easier to spot changes in sales across the year.
- Order-status distribution provides a snapshot of fulfillment outcomes and orders that may need attention.
- Channel analysis helps compare the sales contribution of the Mobile App and Website.
- Together, these views support sales monitoring and can inform planning and operational decisions.
